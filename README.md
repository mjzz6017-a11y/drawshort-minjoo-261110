# ✳ DrawShort

**읽는 이야기에서, 보는 이야기로.**

블로그 주소 또는 원문을 입력해 9:16 세로형 화이트보드 스타일 MP4를 만드는 웹 프로젝트입니다. AI와 대화하며 화면 구성부터 서버, 영상 합성, 임시 공개 연결까지 구현한 바이브코딩 작업입니다.

## 시연

[30초 샘플 영상 보기 / 다운로드](docs/demo.mp4)

샘플은 ‘작은 습관이 만드는 변화’라는 글을 무료 체험 모드로 제작한 결과입니다. 1080 × 1920, 약 30초, 무음 MP4입니다.

[임시 체험 홈페이지](https://edgar-cedar-thrown-keen.trycloudflare.com/)

이 주소는 개발 컴퓨터와 서버·Cloudflare Tunnel이 실행 중일 때만 접속됩니다. 주소가 바뀌거나 접속이 종료될 수 있습니다. GitHub 저장소 자체가 영상 생성 서버를 운영하는 것은 아닙니다.

## 주요 기능

| 기능 | 내용 | 확인 상태 |
| --- | --- | --- |
| 본문 직접 입력 | 제목과 글을 입력해 제작 | 실제 동작 확인 |
| 무료 체험 | 원문 문장 선택 → 기본 그림과 문장 카드 → MP4 | 30초 영상 생성 확인 |
| 영상 미리보기 | 웹에서 영상 재생 | 1080 × 1920 재생 확인 |
| 다운로드 | MP4 및 장면 대본 JSON 제공 | 파일 다운로드 확인 |
| 네이버 블로그 주소 | 공개 게시물의 본문 추출 | 추출 로직 테스트 완료, 실제 게시물 연결 추가 검증 필요 |
| AI 제작 | AI 대본, 장면별 일러스트, 한국어 합성 음성 | 구현 완료, 실제 API 생성 미검증 |

무료 체험은 AI 요약·이미지 생성 없이 원문의 문장과 기본 그림으로 영상을 만듭니다. 장면은 위에서 아래로 나타나는 효과를 사용하며, 펜의 이동 경로를 추적하는 드로잉 방식은 아닙니다.

## 제작 흐름

```text
네이버 블로그 주소 / 본문 직접 입력
                  ↓
       본문 추출 및 장면 구성
                  ↓
무료 체험: 문장 + 기본 그림
AI 제작: AI 대본 + 이미지 + 한국어 음성
                  ↓
       FFmpeg 세로형 MP4 합성
                  ↓
      미리보기 · MP4 다운로드
```

## 실행 방법

Node.js 22 이상과 npm이 필요합니다.

```bash
npm ci
npm start
```

브라우저에서 `http://127.0.0.1:4317`을 엽니다. Windows에서는 설치 후 `START_WINDOWS.bat`를 사용할 수도 있습니다.

1. ‘샘플 글로 먼저 체험하기’를 선택하거나 글을 직접 입력합니다.
2. 제작 방식과 영상 길이를 고릅니다.
3. ‘나의 영상 만들기’를 누릅니다.
4. 완료되면 미리보기에서 재생하고 MP4를 다운로드합니다.

AI 제작은 화면에서 OpenAI API 키를 입력해야 하며 API 사용료가 발생합니다. 키는 해당 요청에서만 사용하고 파일에 저장하지 않습니다. 합성 음성이 사용되며, 음성이 잘리지 않도록 장면 길이를 늘리므로 실제 영상이 선택한 길이보다 길어질 수 있습니다.

## 사용 기술

- 화면: HTML, CSS, JavaScript
- 서버: Node.js HTTP 서버
- 본문 추출: Cheerio
- 이미지 구성: Sharp, SVG
- 영상 합성: FFmpeg (`ffmpeg-static`)
- AI 연동: OpenAI API (대본·이미지·음성)
- 임시 외부 접속: Cloudflare Tunnel

## 파일 구성

```text
web/               웹 화면과 입력·진행 상태·미리보기
server.mjs         작업 생성 API와 영상 제작 처리
lib.mjs            주소 검사, 본문 추출, 장면 구성
test.mjs           주소 및 본문 처리 테스트
docs/demo.mp4      실제 생성한 시연 영상
renders/           로컬 생성 결과 (GitHub 업로드 제외)
```

## 검증 및 현재 한계

`npm test`로 주소 형식, 허용하지 않는 주소 차단, 본문 추출, 문장 카드 구성을 검사합니다. 본문 입력부터 MP4 생성, 웹 재생, 다운로드까지 확인했습니다.

현재는 한 번에 영상 하나를 만드는 체험용 MVP입니다. 사용자 계정, 작업 취소, 보관 기간 관리 기능은 없습니다. 공개 네이버 게시물만 대상으로 하며 접속 제한이나 본문 형식 변경 시 본문 직접 입력을 사용해야 합니다. SVG의 한글 글꼴은 Windows의 맑은 고딕을 기준으로 확인했으며 다른 운영체제에서는 한글 글꼴 설치가 필요할 수 있습니다.

이 저장소에는 이번에 실행·확인한 Node.js 앱을 담았습니다. 이전 Python/Remotion 초안은 포함하지 않았습니다.
